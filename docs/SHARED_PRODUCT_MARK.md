# 共享产品标记设计简报

> 状态：用户已选择“协作节点”，正式 SVG 与 ICO 已接入 Vue 左上角和浏览器 favicon，并通过构建、资源请求及定向浏览器验收。

## 用途

为白标产品建立所有客户共同使用的产品标记。客户只能定制显示名称；首页图标与 favicon 使用同一视觉母版。

## 已确认决策

- 语义重点：AI 辅助工具，不以客户名称、K 线或行情走势为核心。
- 视觉气质：专业、精准、抽象；不使用机器人头像。
- 颜色：琥珀金与深海军蓝，同时准备深色、浅色和单色适配。
- 外轮廓：圆角方形底板加独立核心符号；favicon 和首页图标共用。
- 文字边界：核心符号完全无字母，不使用客户首字母、`H` 或 `AI` 字样。
- 输出：首轮提供 3 个概念版本，分别探索智能核心、协作节点和精准工具；每个版本同时展示首页图标与 favicon 效果。

## 首轮交付约定

- 每个概念提供可缩放 SVG 母版和透明 PNG。
- 每个概念展示当前首页 34×34 像素使用效果。
- 每个概念生成包含 16、32、48 像素图层的 `favicon.ico` 候选文件。
- 首轮仅供比较；用户选定方向后再完成最终接入与验证。

## 首轮候选结果

1. **智能核心**：AI 与决策聚焦语义最完整；确定性重绘后在 16 像素仍可辨识。
2. **协作节点**：小尺寸轮廓最稳定，能表达对等协作；需注意避免被理解为镜头或通用模块图标。
3. **精准工具**：工具与聚焦语义直接；当前轮廓容易被理解为“全屏/展开”，不建议不经修改直接定稿。

生成探索稿保存在 `docs/design-assets/shared-product-mark/concepts/`；可交付的确定性 SVG、PNG 和多图层 ICO 候选保存在 `docs/design-assets/shared-product-mark/candidates/`。

## 正式接入

- 选定方向：`02-collaborative-nodes`。
- 首页资产：`frontend-vue/public/product-mark.svg`，在侧栏品牌链接中固定显示为 34×34 像素。
- 浏览器资产：`frontend-vue/public/product-mark.svg` 为现代浏览器主图标，`frontend-vue/public/favicon.ico` 提供 16、32、48 像素兼容图层。
- 客户显示名称与副标题仍由 `client.brand` / `client.brand_sub` 控制；共享产品标记不读取客户首字母。
