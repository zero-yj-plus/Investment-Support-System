# 维科夫量价分析（Wyckoff + VSA）

> 方法论体系：通过量与价的关系反推主力（聪明钱）是在吸筹还是派发。所有判断须落在真实量价数据上，缺数据不臆测主力行为。

核心：**价由量驱动，跟着主力的脚印走。**

## 一、三大法则
1. **供需法则**：价涨需求>供给，价跌供给>需求。一切归到买卖力量对比。
2. **因果法则**：横盘震荡（区间）积累的"因"决定后续趋势的"果"——震荡越久、换手越充分，后续空间越大（量度目标）。
3. **量价/效果对比法则（Effort vs Result）**：成交量（努力）应与价格变动（结果）匹配。**背离=反转信号**（如放巨量却滞涨=派发；缩量却下跌乏力=吸筹尾声）。

## 二、四阶段（市场循环）
**吸筹(Accumulation) → 拉升(Markup) → 派发(Distribution) → 下跌(Markdown)**，循环往复。判断当前阶段是第一要务。

## 三、吸筹结构（底部区间关键事件）
- **PS 初步支撑 / SC 抛售高潮（放巨量恐慌杀跌）** → **AR 自动反弹** → **ST 二次测试**（缩量不破新低=供给枯竭）。
- **Spring（弹簧/假跌破）**：末端**跌破支撑后快速收回**，洗掉散户止损、测试供给。Spring 后缩量回踩不破 = 强力做多信号。
- **SOS 强势信号**：放量突破区间上沿，进入拉升。
> A股映射：底部缩量、跌不动、假破位后放量拉起 = 吸筹完成、可低吸卡位。

## 四、派发结构（顶部区间关键事件）
- **PSY 初步供给 / BC 买入高潮（放巨量冲高）** → **AR** → **UT 上冲回落**。
- **UTAD（派发后上冲/假突破）**：末端**突破前高后快速跌回区间**，是 Spring 的镜像——诱多出货信号。
- **SOW 弱势信号**：放量跌破区间下沿，进入下跌。
> A股映射：高位放量滞涨/天量长上影、假突破新高后跌回 = 派发，应兑现/回避。

## 五、VSA 量价信号（微观读盘）
- **无需求 (No Demand)**：上涨却缩量、窄幅 → 上方无承接，涨不动。
- **无供给 (No Supply)**：下跌却缩量、窄幅 → 下方抛压枯竭，跌不动（吸筹信号）。
- **高潮量 (Climax)**：异常放量 → 多空力量耗尽，常是阶段转折。
- **努力≠结果**：放量滞涨（派发/出货）、缩量上涨（轧空/惜售）都要警惕背离。

## 在本系统怎么用
- 复盘的"情绪周期定位"用量价确认：**放量滞涨=派发（警惕退潮）**；**缩量回踩不破=洗盘（可低吸）**；指数/龙头的量能配合判断主升真假。
- 趋势票筛选结合维科夫：健康放量+均线多头=拉升中段可做；放量滞涨/量价背离=过热慎追。
- 判断个股"放量是进攻还是出货"：看量价配合位置（低位放量突破=进攻，高位放量滞涨/长上影=出货风险）。
- 与情绪周期（宏观相位）、龙头战法（个股梯队）配合：维科夫给"主力在吸还是派"，情绪周期给"市场在哪个相位"。
