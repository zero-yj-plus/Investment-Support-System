# 情绪周期（A股短线核心相位框架）

> 方法论体系：先定相位，再定攻防与仓位。所有判断必须落在当日真实 snapshot 指标上，缺数据标注，绝不臆测。

短线市场像潮汐，循环走 **冰点 → 修复 → 发酵 → 主升/高潮 → 分歧 → 退潮 → 冰点**。判断"市场在哪个相位、哪个节点"是短线一切决策的前提，直接决定攻防与总仓位（与炒股养家"低位空、高位满"一致）。

## 核心量化指标（都来自当日真实数据）
涨停数、最高连板高度、连板梯队是否完整/断层、**昨日涨停今日表现的晋级率与平均涨幅**、炸板率=炸板/(涨停+炸板)、跌停数、两市成交额（量能环比）、指数位置。

## 七个相位与判据
- **冰点**：跌停≥涨停、涨停极少、高度1-2板、人气股大面、缩量 → 操作：等首阴反包/超跌低吸的种子，不打板；仓位 0-2 成。冰点次日往往是大分歧低吸点。
- **修复**：跌停消失、首板晋级率回升、出现2-3板赚钱效应 → 操作：低吸卡位、试仓打首板；仓位 2-4 成。
- **发酵**：连板高度抬升（4板+）、梯队完整、量能放大、题材扩散 → 操作：打板/卡位/半路占优，敢做；仓位 5-7 成。
- **主升/高潮**：高度板加速、空间打开、情绪一致、天量 → 操作：持有兑现并存，警惕见顶；仓位 6-8 成→开始减。
- **分歧**：最高板封不住/大长腿、炸板率飙升、晋级率见顶回落 → 操作：卖龙头兑现、只留核心、降仓；仓位降到 3-4 成。
- **退潮**：高度板倒、晋级率骤降、跌停回来、缩量 → 操作：防守/空仓，只低吸超跌反包，禁止低吸接力；仓位 0-3 成。

## 相位切换信号（节点判断）
- **冰点反转**：首阴反包成功、跌停消失、首板放量晋级 → 进修复。
- **加速**：高度板顺利晋级 + 新2/3板批量补梯队 → 发酵转主升。
- **见顶/分歧**：最高板炸板或巨量长上影、炸板率>30%、晋级率从高位掉头 → 主升转分歧/退潮。
- **退潮确认**：空间龙头断板带出跌停、晋级率<15% → 防守。

## 量价配合（结合维科夫量价）
放量滞涨=派发（警惕高潮见顶）；缩量回踩不破=洗盘（可低吸）；指数与连板数/高度的趋势是否同向，背离要警惕。

## 在本系统怎么用
复盘的"情绪周期定位"用本框架给**唯一明确结论**（在哪个相位、哪个节点）；据此在次日策略里给总仓位与攻防基调——退潮/冰点就明确建议轻仓或休息，不硬找票。结论必须由真实指标支撑。
