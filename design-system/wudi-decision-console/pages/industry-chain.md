# 产业链研究页规则

> 路由：`#/research?tab=chain`。本页只承载产业链结构化研究，不迁移公司研究、海外市场或其他研究页。

## 页面任务

1. 先说明产业结论与当前交易时点严格分离；没有风险闸与实时个股证据时，不给价格、仓位或买卖动作。
2. 唯一主动作是输入行业/产业链并“开始研究”；生成中只能停止，完成后才允许重新研究或存入知识库。
3. 首屏同步显示证据时点、来源覆盖和缺口；模型不可用时，确定性 TDX 板块/成员骨架仍可工作。
4. 公司映射只表示真实 TDX 板块成员及证据核验顺序，不等于产业角色、投资排名或推荐。

## 信息顺序

1. 页面标题、研究边界、证据时点与生成状态。
2. 行业输入与唯一主动作。
3. 产业结论、当前交易时点、禁止条件。
4. 需求本质、产业地图、价值捕获、卡点和国产替代。
5. 公司映射、兑现与估值、研究优先级、失效条件。
6. 完整安全 Markdown、证据缺口、数据治理与本地历史。

## 数据与状态

- 生产请求固定为 `POST /api/chat`，`mode: chain`，`research_contract: chain-research-v2`；不为本页触发其他重型行情接口。
- SSE 的 `stage`、`delta`、`done`、`error` 分开处理；未知事件忽略。停止或断流后的部分正文必须标为“不完整”，不得保存或作为下一轮依据。
- 后端明确的 `缺失`、`未知`、`—`、真实空公司映射和传输失败不得合并。接口没有独立 `stale` 字段时，只显示证据时点并声明“未暴露陈旧判定”。
- 现价单位为元，涨跌幅为百分比，PE/PB 为倍数；数据可研分无量纲，只用于证据核验排序。
- `POST /api/knowledge` 仅在用户主动操作时调用；成功文案只能是“已写入知识库”，不能声称已审批或已进入模型知识。

## 组件与交互

- 页面拆为输入/状态、结论边界、研究正文、历史与治理组件；请求、SSE reader、超时和本地历史由 composable 管理。
- 输入使用带可见 `label` 的原生 `<input>`；研究、停止、重试、保存、历史切换使用原生 `<button>`；公司诊断使用真实 `<a>`。
- 所有可见交互目标至少 44×44px，`:focus-visible` 使用项目 3px 焦点环；错误使用 `role="alert"`，进度使用 `role="status"` 和 `aria-live="polite"`。
- Markdown 必须经 `parseReportMarkdown()` 转为 Vue 文本节点；禁止 `v-html`、`innerHTML` 和运行时 HTML 注入。
- 页面卸载时取消研究与保存请求、SSE reader、超时及监听；generation guard 阻止卸载后的响应更新状态。

## 布局与响应式

- 桌面使用“主研究区 + 264px 历史/治理侧栏”；低于 1040px 改为单列，侧栏不得 sticky 遮挡正文。
- 研究证据默认单列，产业地图在宽屏为三列；低于 720px 全部改为单列，正文基准 18px。
- 公司 Markdown 表格仅在自身可聚焦容器内横向滚动；页面根和卡片必须 `min-width: 0`，不得出现页面级横向滚动。
- 200% 缩放后输入、主动作、停止和研究正文仍可操作；不通过缩小字号塞入桌面布局。

## 视觉覆盖

- 完全沿用 `MASTER.md` 的亮/暗令牌、1px 边框、8px 圆角和无装饰阴影。
- 不采用技能检索返回的玻璃拟态、巨型 Hero、渐变或霓虹；产业结构、交易时点、缺口均以文字标签和边框区分，不依赖颜色。
- 数字使用等宽字体和 `tabular-nums`；数据标签不低于 12px。

## 审计状态

- 审计 fixture 覆盖：初始空态、生成加载态、确定性完整结果、TDX 未匹配的真实空结果、局部/流式失败。
- 固定检查 375px 深色、1440px 深色、1440px 浅色；axe WCAG 2.1 AA、44px 目标、页面溢出和表格局部滚动必须通过。
