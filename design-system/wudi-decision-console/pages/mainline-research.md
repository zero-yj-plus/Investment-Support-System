# 主线深研页面规则

> 页面路由：Vue Hash `#/today?tab=mainline`。本文件只覆盖主线深研页；未声明部分继承 `../MASTER.md`。

## 用户任务与信息顺序

页面首先帮助个人 A 股投资者判断主线是否成立、现在应观察或回避什么，以及结论的证据覆盖和时效性。信息顺序固定为：

1. 页面标题、交易日、主线快照时点和数据状态。
2. 题材赚钱效应与因子覆盖。
3. 交易拥挤度与分歧风险。
4. 跨日持续性和切换信号。
5. 连板梯队、人气承接与领涨角色明细。
6. 数据来源、覆盖、规则口径与缺失说明。

## 业务语义

- 主线排名、分数、领涨角色和切换信号仅展示服务端结果，前端不得重新计算或补齐。
- `null` / 字段缺失显示“— / 未提供”；`missing` 显示“数据缺失”；`degraded` 显示“降级数据”；真实空数组显示“当前没有形成主线”；接口失败显示“该部分暂不可用”。
- last-good 必须显示原始快照时点并标注“历史快照”，不得称为实时。
- 百分比字段保留接口单位；资金字段只有在契约明确单位时才格式化，不凭字段名推断。
- 接口局部失败不能隐藏已成功返回的其他区域。

## 布局与组件

- 页面采用单一主内容列；桌面端“当前结论 / 风险边界”可组成 `minmax(0, 1fr) 320px` 双栏，低于 900px 改为单栏。
- 候选主线使用可扫描的纵向卡片，不使用装饰性图表。每张卡同时展示阶段文字、总分、因子明细、证据覆盖和缺失项。
- 高密度明细优先使用标签—值记录；确需表格时，移动端转换为堆叠记录，表格仅在自身可聚焦容器中横向滚动。
- 状态徽标除颜色外必须有明确文字；行情涨跌色不得承担主线阶段或风险含义。
- 页面不设置 sticky 侧栏，避免 200% 缩放和移动端遮挡正文。

## 交互

- 刷新使用应用顶栏原生 `<button>`，请求进行中禁用并显示“刷新中”；页面内容区不重复放置动作表单。
- 可跳转到个股诊断的股票代码/名称使用真实 `<a>`；无目标路由时只显示文本，不伪装链接。
- 展开因子或治理说明的按钮维护 `aria-expanded` 和 `aria-controls`。
- 每个交互目标至少 44×44px，并提供清晰 `:focus-visible`。
- 刷新结果通过 `aria-live="polite"` 宣告；加载、空、降级和错误不自动抢焦点。

## 响应式与无障碍

- 375px 起采用单列、18px 正文；768px 以上逐步增加信息并列，桌面正文为 16px。
- 页面根和卡片使用 `min-width: 0`、可换行文本和受控表格溢出，禁止页面级横向滚动。
- 低于 720px 将表头/行转换为标签—值堆叠，不通过缩小字号硬塞内容。
- 语义标题连续；页面主体使用 `<main>`，独立证据区使用带可读标题的 `<section>`。
- 深浅主题文字和边界满足 WCAG 2.1 AA；支持 `prefers-reduced-motion: reduce`。

## 状态验收

- 加载态：各请求区域独立骨架或文字状态，保留最终布局高度。
- 空数据态：成功且真实空数组时明确说明“当前没有形成主线”，不显示错误重试语气。
- 局部失败态：失败区域提供重试，其他成功区域维持可读。
- 陈旧态：显示数据日期、快照时间和 last-good 标签。
- 治理态：展示规则版本、覆盖率、数据来源和未提供字段，不生成示例数字。
