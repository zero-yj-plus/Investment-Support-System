# 盘前报告页面规则

本页继承 `MASTER.md`。它服务于“开盘前计划确认”，不是资讯流或行情看板。

## 信息顺序

1. 页面说明：报告日期、生成时点和“盘中验证不改写盘前事实”的口径。
2. 定格决策：风险等级、今日动作、仓位边界、第一原则和允许/禁止项。
3. 重点方向：盘前资金排序与盘中资金验证并列展示；验证层只提示偏差。
4. 报告工作区：桌面端左侧章节目录、右侧正式定稿；正文保持单一阅读列。
5. 报告治理：版本、内容指纹、推送状态与“候选提案非下单指令”说明。

## 交互与数据

- 读取 `/api/reports/morning?date=YYYY-MM-DD`；无报告时显示明确空态，不生成示例内容。
- 读取 `/api/market/flow` 作为盘中方向验证；失败不影响报告和盘前快照展示。
- 方向验证每 30 秒刷新，页面恢复可见时补刷新；卸载时取消报告、资金、生成和推送请求并清理定时器。
- 生成使用 `/api/reports/morning/generate` SSE；不完整流不得冒充正式报告。
- 推送使用 `/api/reports/morning/push`，按钮在请求期间禁用并显示状态。
- Markdown 必须解析为安全的 Vue 节点；禁止直接用未清洗的 `v-html`。

## 响应式

- 900px 以上：报告目录 268px，正文 `minmax(0, 1fr)`；目录可 sticky，页面只保留主滚动。
- 900px 以下：目录移到正文上方；手机端为单列，目录可折叠。
- 宽表放入可聚焦的局部横向滚动容器，页面本身不得横向滚动。
- 正文最大阅读宽度约 940px；移动端正文 18px，桌面端 16px。

## 验收

- 375 / 768 / 1024 / 1440px 无页面级横向滚动，所有交互目标至少 44×44px。
- 深浅主题分别通过 WCAG 2.1 AA；风险等级同时显示文字和固定色。
- 键盘可依次操作导航、目录、导出、推送、生成/刷新动作；章节跳转后标题可聚焦。
- 支持 `prefers-reduced-motion`；打印样式隐藏导航与交互控件，保留定格决策和正式正文。
