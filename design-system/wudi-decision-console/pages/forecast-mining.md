# 业绩预告掘金页面规则

> 本页覆盖 `../MASTER.md`。业务口径沿用旧版“业绩预告掘金”；不把预告等同于正式业绩报告，也不在浏览器重算候选结论。

## 用户任务与信息顺序

1. 首屏说明数据期间、抓取时点、候选数量与当前筛选结论。
2. 唯一主动作是刷新服务端榜单；不提供浏览器侧生成、打分或推荐动作。
3. 紧邻结论展示使用边界：预告不等于定稿、候选不等于推荐、缺失字段不可推断。
4. 结构化证据按服务端标签、业绩区间、变动幅度、披露时点与疑点组织。
5. 候选明细保留服务端顺序；桌面为可聚焦的宽表容器，移动端转换为卡片。
6. 页面底部说明来源、单位、数据日期、新鲜度和降级状态。

## 状态语义

- `loading`：保留稳定骨架和明确加载文字。
- 真实空数组：显示“当前口径下无候选”，不视为接口失败。
- `missing` / `null`：对应值显示 `—` 并附“未披露/缺失”文字，不补 0。
- `degraded`：保留可用数据，同时以文字说明覆盖不完整或来源降级。
- 陈旧数据：显示真实数据日期/抓取时点与“陈旧”标签，不称为实时。
- 传输失败：只降级榜单区域，保留页面说明和重试按钮。

## 视觉与交互

- 使用 1px 边框、8px 圆角、无阴影；遵循 4/8px 间距体系。
- 业绩增长/下降可使用行情涨跌色，但“疑点”“缺失”“降级”使用独立风险/状态色，并始终配文字。
- 金额、百分比、日期和代码使用等宽数字与 `tabular-nums`；数字字号高于相邻解释文字。
- 刷新使用原生 `<button>`，诊断跳转使用真实 `<a>`；可见交互目标不小于 44×44px。
- 预告类型统计使用原生按钮筛选当前服务端结果；股票代码搜索使用带可见标签的原生搜索框。两类筛选均不改变服务端分池与排序。
- 焦点环清晰；状态变更使用 `aria-live="polite"`，失败使用 `role="alert"`。
- 不使用装饰图标、渐变、阴影或只靠颜色表达标签含义。

## 响应式与无障碍

- 900px 以下单列；720px 以下候选表切换为卡片，不靠缩小字体塞入桌面列。
- 页面级不得横向滚动；桌面宽表只在带 `tabindex="0"` 和可读名称的容器内滚动。
- 375px 下正文基准 18px，标签不低于 12px；长公司名、标签和错误文本允许换行。
- 200% 缩放时结论、刷新、状态说明和候选核心字段仍可读可操作。
- 遵守 `prefers-reduced-motion`，不添加非必要进入动画。

## 生命周期与数据边界

- 榜单请求使用独立 `AbortController`；刷新先取消同类旧请求，并防重复提交。
- 页面卸载时取消请求、移除 `visibilitychange` 监听并清理刷新定时器；卸载后的响应不得写入状态。
- 生产组件不得包含示例候选或演示数字；固定 fixture 仅允许存在于 `scripts/audit-ui.mjs`。
- 页面只消费本业务真实接口，不触发模型、报告生成、推送或其他研究页重型请求。

## 接口与单位

- 唯一接口：`GET /api/forecast/mining`。
- 顶层：`ok`、`ts`、`period`、`deadline`、`stats`、`items`、`traps`、`missing[]`。
- `p_chg_min/p_chg_max` 单位为 `%`；`net_min/net_max/last_net` 原始单位为人民币元；`ann_date` 为 `YYYYMMDD`。
- `mandatory/layer/trap/trap_reason/nonrec_flag/is_new_today` 是服务端规则事实，只展示、不重算。
- 当前契约没有独立 `data_date`、`stale` 或 `degraded` 字段；`ts` 只标服务端计算时点，不得称为公告数据日期或实时性证明。
