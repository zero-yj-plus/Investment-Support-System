# 舆情事件页规则

> 本页规则覆盖 `MASTER.md` 的页面级信息架构；未声明部分继续遵循全局设计系统。

## 页面任务

帮助个人 A 股投资者快速判断：当前有哪些可核验事件、它们映射到哪些 A 股实体、后续盘面证据是否已形成。新闻映射只表示结构化关联，不代表因果、利多利空或交易建议。

## 信息顺序

1. 标题、数据日期、最近抓取时点与刷新动作。
2. 请求失败、真实空结果或采集链不可用等必要状态反馈。
3. 事件筛选与事件流：按市场范围和搜索词筛选，不在浏览器中重新判断情绪方向。
4. 单个事件的来源、发生/抓取时点、摘要、A 股股票/行业/概念映射与后续观察。
5. 数据健康、降级来源、陈旧状态和缺失说明；不额外占用首屏设置结论、计数或风险边界摘要卡片。

## 状态语义

- `loading`：保留稳定骨架并显示“正在获取舆情事件”。
- 真实空数组：显示“当前范围暂无事件”，不得解释为接口失败。
- `missing`：字段显示“—”或“未提供”，不得补 0、示例文本或推断值。
- `degraded`：保留已返回事件，并逐项标明降级来源或覆盖不足。
- 接口失败：事件区域局部显示“暂不可用”与重试按钮，不影响页面壳和数据边界说明。
- 陈旧：显示真实数据日期/抓取时点和“数据可能陈旧”，不得标成实时。
- 后续观察缺失：显示“待观察”或“暂无盘面观察”，不得解释为无影响。

## 数据契约

本页只读取 `GET /api/news/a-share`，不为首屏额外请求观察历史或对账接口。

| 字段 | 单位 / 口径 | 缺失语义 |
|---|---|---|
| `cn_fetched_at` / `fetched_at` | 新闻聚合/证据抓取时点 | `null` 或缺失显示“—”，不得替代事件发生时点 |
| `latest_event_time` | 最新事件来源时间 | 缺失显示“—” |
| `refresh_seconds` | 秒 | 缺失不展示推断频率；实现按服务端既有 30 秒契约刷新 |
| `sources_tried` / `sources_live` | 采集端个数 | 缺失显示“—”；0 仅在服务端明确返回时显示 |
| `missing[]` / `pipeline.*` | 覆盖与各链路状态 | 任一链路降级只影响对应说明，保留已返回事件 |
| `items[]` | 真实事件数组 | 成功响应的 `[]` 为真实空结果；传输失败或 `source_state=unavailable` 不得冒充空结果 |
| `published_at` / `time` | 事件来源时间 | 缺失显示“未提供” |
| `observations[].fetched_at` | 单个采集端抓取时点 | 缺失显示“未提供” |
| `corroboration.*_count` | 采集端/独立来源计数 | 缺失显示“—”；多端命中不等于独立信源确认 |
| `a_share.state` | `mapped/candidate/none/unavailable` | 缺失显示“映射状态未提供”，不猜实体关系 |
| `a_share.matches[]` / `topic_candidates[]` | 公司、行业、概念和主题候选 | 空数组为无明确映射；候选不得冒充直接映射 |
| `observation.status` | `waiting/observing/observed/incomparable` | 缺失显示“暂无盘面观察” |
| `progress.complete/total` | 已记录/目标时点个数 | 任一缺失显示“检查进度未提供”，不得补 0 |
| `since_baseline_pct` / `change_pct` / `median_change_pct` / `up_ratio_pct` | 百分数 | `null` 显示“—”，不得参与浏览器端结论计算 |

## 组件与交互

- 页面只提供一个主动作“刷新事件”；加载中禁用，防止重复提交。
- 筛选控件使用原生 `button` 和带可见标签的 `input`；来源链接使用真实 `a`。
- 事件条目使用 `article`，标题层级连续；展开观察详情的按钮维护 `aria-expanded`。
- 股票、行业、概念映射使用文字标签并明确映射类型，颜色不得表达利多或利空。
- 时间与计数使用等宽数字；数字大于相邻解释标签。
- 长 URL、标题和摘要允许换行；不得造成页面级横向滚动。

## 响应式覆盖

- `>= 1024px`：筛选栏与事件流纵向排列；事件元信息可使用紧凑网格，正文保持单一阅读主线。
- `< 768px`：事件卡改为单列，筛选按钮可换行；摘要、映射、观察按阅读顺序堆叠。
- 宽明细只允许在自身可聚焦容器内横向滚动；优先转换为堆叠行，手机端不使用宽表。
- 375px 与 200% 缩放下，刷新、筛选、展开、重试等可见交互目标保持至少 44×44px。

## 禁止项

- 不给新闻自动添加“利好/利空”、风险等级、仓位或买卖建议。
- 不把实体映射写成事件因果关系。
- 不用事件总数或空值虚构市场热度。
- 不把抓取时点当作事件发生时点；两者必须分别标注。
- 不因任一来源失败清空其他来源的有效事件。
