# 系统设置页规则

> 本页覆盖 MASTER 的通用决策页顺序。设置页首先回答系统是否具备可靠运行条件、当前最应处理的阻断项，以及各配置是否已安全生效；不生成或重算交易结论。

## 路由与接口边界

- 设置分区路由：`#settings-tasks`、`#settings-delivery`、`#settings-models`、`#settings-data`、`#settings-governance`；旧入口 `#/settings?tab=system` 兼容并默认进入任务计划。
- 只读：`GET /api/settings`、`GET /api/status`、`GET /api/jobs`、`GET /api/datasources`、`GET /api/delivery/readiness`、`GET /api/delivery/receipts`、`GET /api/delivery/outbox`、`GET /api/agent/runs`、`GET /api/settings/model-connections`。
- 设置动作：`PUT /api/settings`、`POST /api/push/test`。
- 模型动作：`POST /api/settings/model/test`、模型连接 CRUD 与 activate 端点。
- 运行动作：`POST /api/jobs/{job_id}/run`、`POST /api/delivery/{delivery_id}/acknowledge`、`POST /api/delivery/{delivery_id}/retry`。
- 不请求行情、筛选、持仓、报告生成或其他业务页接口；共享 App 壳请求不属于本页业务请求。

## 用户任务与信息顺序

1. 页首展示“系统设置”、最近检查时点、整体就绪结论与唯一主动作。
2. 紧接着展示阻断项、降级项和无需处理的正常项；状态必须有文字，不能只靠颜色。
3. 任务计划承载任务时间与运行状态，交付推送承载交付与推送，模型连接承载自定义模型连接，数据健康承载数据健康与部署，版本治理承载版本、安全与运行边界。
4. 每个分区只渲染自己的配置面板；全局就绪摘要保留，并可跨分区直达待处理项。
5. 不展示与设置无关的行情、风险等级、仓位或推荐接口数据。

## 布局

- 桌面采用 `minmax(0, 1fr)` 主配置区与 320px 状态摘要栏；低于 960px 改为单列。
- 配置分组使用单层卡片，不以多层嵌套卡片制造层级。
- 表单标签始终可见；说明、单位、缺失语义和保存反馈靠近对应字段。
- 手机端按“就绪结论 → 待处理事项 → 配置分组 → 治理说明”排列，操作栏不得固定遮挡内容。
- 长 URL、模型名和版本号允许断词；页面级不得横向滚动。

## 状态与动作

- 整体状态至少区分：加载中、可用、部分就绪、未就绪、检查失败。
- 单个接口失败只降级其对应分组，已成功加载的设置继续可查看；涉及覆盖写入的分组在读取失败时禁用保存。
- 缺失配置显示“未配置”，布尔关闭显示“已关闭”，服务端降级显示“部分可用/已降级”，真实空列表显示“暂无连接/暂无任务”；不得混为 `—` 或 `0`。
- 保存、测试、切换、重试均使用原生 `<button>`，防重复提交并在按钮附近提供 `aria-live="polite"` 反馈。
- 页面内跳转使用真实 `<a>`；危险或不可逆操作需要明确说明影响范围并二次确认。
- 推送状态严格区分“已提交”“平台接受”“已送达”；测试推送成功不得自动表述为最终送达。

## 表单与敏感信息

- API Key、Webhook、Secret 等敏感值仅展示“已配置/未配置”，不得回填明文；空输入默认表示保持现值，清除动作必须单独且明确。
- 服务端校验错误显示在对应字段旁，并保留用户输入；全局错误不替代字段错误。
- 输入框、开关、按钮和链接可见触控区域不小于 44×44px；键盘顺序与视觉顺序一致。
- `:focus-visible` 使用 3px 高对比焦点环；状态切换兼容 `prefers-reduced-motion`。

## 视觉语义

- 延续 MASTER 的 1px 边框、8px 圆角、无阴影和 4/8px 间距体系。
- 就绪度使用信息/警示/错误语义色，不复用行情涨跌色；每个状态同时显示名称和简短原因。
- 版本号、端口、模型标识、任务时点等使用等宽数字与 `tabular-nums`。
- 高密度配置通过分组标题、描述列表和细分隔线组织，不使用巨型标题、装饰图标或渐变。

## 审计状态夹具

审计脚本可以提供固定但明确标注的设置 fixture，至少覆盖：完整就绪、敏感项未配置、真实空模型连接、局部接口失败、加载中和保存反馈。生产组件不得内置这些值。

## 技能查询取舍

- 采用 `ui-ux-pro-max` 的 Vue Composition API、显式 label、就地提交反馈、44px 触控目标、移动端卡片化宽表和 `prefers-reduced-motion` 建议。
- 技能搜索建议锚点平滑滚动，但 reduced-motion 下必须改为即时滚动；不引入路由库或全局 Store，因为本页沿用现有轻量 Hash 路由和局部 composable 即可。
- 宽表只在带 `tabindex="0"` 和可读名称的自身容器中横向滚动；页面根不得横向滚动。
