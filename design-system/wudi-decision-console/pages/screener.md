# 条件选股页覆盖规则

> 继承 `../MASTER.md`。本页只覆盖条件选股的任务顺序、状态语义和响应式行为；颜色、字体、间距与全局组件规则仍以 Master 为准。

## 页面任务

帮助个人 A 股投资者先确认筛选是否具备足够覆盖率，再提交服务端确定性筛选，并把真实结果作为后续个股诊断入口。前端不得重算评分、排名、价格条件或风险结论。

## 数据契约

- 主请求为 `POST /api/screen`，只在用户明确提交或刷新本页时触发；普通挂载不自动请求全市场筛选。
- 表单的流通市值和成交额输入单位为亿元，后端换算为元；结果的 `price/circ_mv/amount` 单位为元，`change_pct/turnover_rate` 为百分数，`volume_ratio/pe_ttm/pb` 为倍数。
- `coverage.sufficient=false` 或 `ok=false` 时不得展示为可用全市场结果；当前服务端最低覆盖门槛为 80%，页面展示返回门槛而不自行放宽。
- `stocks=[]` 结合 `ok/missing/coverage` 区分真实无命中与不可筛选；明细 `null` 显示 `—`。
- `analysis_contract.decision_authority=candidate_only` 表示仅生成候选；下一步是真实链接进入 Vue 个股诊断。
- 结果行的 `POST /api/watchlist` 是次动作；`zone_status=queued` 只显示“平台已接受、计算已排队”，不得表述为区间已完成。

## 信息顺序

1. 页面标题、服务端数据日期、筛选口径与结果生成时点。
2. 本次筛选结论：可用结果数、覆盖状态，以及唯一主动作“开始筛选”或失败后的“重新筛选”。
3. 执行边界：筛选只缩小研究范围，不等于推荐或买入结论；覆盖不足、降级、陈旧或失败必须先于结果解释呈现。
4. 条件面板：按基础行情、估值/规模、交易特征和多因子模式分组；每项使用原生标签与表单控件。
5. 结果明细：桌面表格、移动端堆叠卡片；股票代码使用真实链接进入 Vue 个股诊断页。
6. 数据健康：来源、股票池覆盖率、总股票数、已扫描数、状态、错误与缺失说明。

## 交互规则

- 主动作使用原生 `<button type="submit">`，筛选期间禁用并显示进行中反馈，防止重复提交。
- 保留旧版五个策略预设作为条件回填快捷方式；预设必须明确展示实际条件、允许继续修改，且选择预设本身不自动提交。
- 条件控件必须有可见 `<label>`；范围输入的错误紧邻对应字段，并通过文字说明，不能只改边框颜色。
- 输入值为空表示“不限制”；不得在前端把空值改写为 `0`。
- 重置只恢复接口契约允许的初始条件，不自动提交请求；筛选表单内不放置结果排序控件。
- 结果明细参照涨停股明细，以原生按钮直接在数值列表头提供排序，不设置独立的排序字段或方向表单。可排序列仅限现价、涨跌幅、换手率、量比、PE TTM、PB、流通市值、成交额。
- 首次点击列表头按从高到低，再次点击切换为从低到高；按钮必须同步方向箭头、可访问名称和表头 `aria-sort`。
- 表格排序只重排当前返回的最多 300 条结果，不重新请求、不改变 `matched`、覆盖率或候选集合；缺失值始终排在末尾。
- 结果代码和名称的跳转使用真实 `<a>`；执行动作不得用链接或伪造 ARIA 角色。
- 接口失败在结果区域局部显示并提供重试，不得清除仍可见的条件输入，也不得拖垮应用壳。
- 加载、真实空数组、`missing`、`degraded`、陈旧和传输失败分别展示，不合并为同一种“暂无数据”。

## 结果与数字

- 价格单位为元；涨跌幅与换手率单位为百分数；市值单位必须按接口契约标注后再格式化。
- 所有数字使用等宽字体和 `tabular-nums`；缺失显示 `—` 并提供缺失说明，不显示 `0` 或示例值。
- 评分、通过条件和覆盖率只展示接口返回值；当前结果的展示顺序可由用户调整，颜色不能作为涨跌、通过或风险状态的唯一线索。
- 宽表只允许在自身带 `tabindex="0"`、可命名的容器内横向滚动；页面本身不得横向滚动。

## 响应式

- `>= 1024px`：条件面板采用紧凑多列网格，结果使用语义表格。
- `768–1023px`：条件面板减少列数，操作区换行但保持按钮至少 44×44px。
- `< 768px`：按任务顺序单列；结果表转换为卡片/堆叠行，重要结论、代码名称与关键数值优先，不通过缩小字体硬塞。
- 375px 下正文基准 18px，控件与按钮满宽或自然换行；200% 缩放后仍可完成筛选和进入诊断。

## 状态与无障碍

- 首次加载和提交加载预留结果区域尺寸；超过 300ms 才显示骨架或明确加载文案。
- 表单错误和接口失败使用 `role="alert"`；结果数量与完成反馈使用 `aria-live="polite"`。
- 表格包含 `<caption>` 或等价可访问名称；移动卡片保持连续标题层级。
- `:focus-visible` 使用全局 3px 焦点环；所有可见交互目标至少 44×44px。
- `prefers-reduced-motion: reduce` 下取消非必要过渡和加载动画。

## 禁止项

- 不展示演示股票、演示数量或猜测条件。
- 不把筛选结果包装成推荐、买入信号或仓位建议。
- 不因共享页面装配触发与条件选股无关的重型请求。
- 不使用 `v-html` 渲染接口文本或 Markdown。
