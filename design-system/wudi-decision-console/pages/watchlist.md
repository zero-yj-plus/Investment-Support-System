# 观察池页面规则

本页继承 `../MASTER.md`，仅覆盖 `#/risk?tab=watchlist`。页面服务个人 A 股投资者，管理“想买但尚未买”的标的，并优先回答当前是否存在可观察机会、下一步动作、价格与失效边界，以及数据是否完整及时。观察池是研究与等待清单，不是下单指令。

## 信息顺序

1. 页面标题、页面说明，以及右侧横向排列的动作：左侧“重算双周期区间”，右侧“添加观察”；不展示独立摘要统计面板。
2. 新增观察标的入口使用模态弹框，避免表单插入内容流后顶动已有观察项；代码先经真实报价核验，不使用示例或猜测名称。
3. 观察项明细：代码、名称、评级/状态、现价、涨跌幅、超短线区间、波段区间、失效条件和备注。风险边界等级是服务端计算结果，不是用户填写项；本接口不提供仓位上限，页面不得推断仓位。
4. 数据来源、降级状态、区间算法版本与治理说明。

## 真实接口与单位

- `GET /api/watchlist`：读取服务端观察池及确定性区间。价格、区间上下沿单位为人民币元；涨跌幅单位为百分比。评级、状态、区间、失效条件和排序均以服务端返回为准，浏览器不重算。
- `GET /api/quote/{code}`：仅在用户新增代码时核验真实证券代码、名称和报价；严格区分 `complete`、`not_found` 与 `quote_unavailable`，报价缺失不补 0。
- `POST /api/watchlist`：新增单条观察记录；`PUT /api/watchlist/{id}`：更新单条记录；`DELETE /api/watchlist/{id}`：删除单条记录。成功只表示账本写入完成且派生区间已排队计算。
- `POST /api/watchlist/recalculate`：用户明确触发时把全观察池区间重算排入后台；`zone_status=queued` 不能表述为已计算完成。
- 页面不得请求报告、推荐统计、全市场筛选或其他与观察池无关的重型接口。

## 缺失与降级

- `null`、字段缺失或显式 `missing` 展示“缺失/未提供”，不得补为 0。
- `items: []` 是真实空观察池，应提供新增动作；与加载失败、`degraded` 和陈旧快照分别展示。
- `degraded` 保留可用的同交易日快照，同时展示降级原因、数据日期和算法版本；不得标为实时。
- 任一观察项的报价或区间缺失只降级该字段/该项，不影响其他观察项和编辑功能。
- 报价日期、区间数据日期或更新时间早于当前服务端交易日时必须显示“陈旧”。

## 交互与生命周期

- 读取、代码核验和保存分别使用独立 AbortController；卸载时全部取消，并以 generation guard 阻止卸载后的响应写入状态。
- 自动刷新只更新读取结果，不得在用户有未保存编辑时覆盖草稿；页面恢复可见时按相同规则补刷新。
- 核验和保存均防重复提交，错误就近显示并通过 `aria-live` 宣告。
- 新增与编辑使用原生 `<dialog>` 模态语义，桌面采用紧凑三列字段编排，保存栏固定在弹框底部；打开后聚焦首个字段，关闭后恢复触发按钮焦点。按 Esc 可关闭，忙碌提交时禁止误关。
- 可跳转代码使用真实 `<a>`；新增、删除、核验、保存和刷新使用原生 `<button>`。所有可见交互目标至少 44×44px。
- 不使用未经清洗的 `v-html`；备注按纯文本显示。

## 响应式

- 900px 以上使用对齐的单行紧凑列表，表头采用浅色中性底与黑色文字；每行直接展示评级、标的、状态、现价、生效区间、双周期区间、风险边界和操作。用户条件与数据治理信息通过行内“详情”按钮渐进展开。评级方块只显示放大的 A—E 结果，不重复附加说明文字。数值启用 `tabular-nums`。
- 标题栏动作始终保持横向双列；1100px 以下两列等宽并完整换行，不改为上下排列。编辑区使用单列布局。
- 900px 以下列表行自动重排为两层；680px 以下按“标的与操作 → 服务端状态 → 当前价与生效区间 → 双周期证据 → 风险边界”纵向分组，不以缩小字体硬塞内容。
- 本页不使用需要横向滚动的传统宽表；页面根不得产生横向滚动。
- 375px 下表单控件、动作区与字段值完整换行；200% 缩放后仍可读取和操作。

## 验收

- 路由可达，仅消费观察池所需真实接口。
- 加载、真实空数组、局部缺失、降级/陈旧、读取失败、核验失败和保存失败均有独立状态。
- 深浅主题满足 WCAG 2.1 AA；状态除颜色外始终带文字，风险色与涨跌色分离。
- 375px 与 1440px 无页面级横向滚动，无小于 44px 的可见交互目标。
- 生产组件不含固定股票、示例价格或浏览器生成的交易结论；固定 fixture 只存在于 UI 审计脚本。
