# 今日复盘页面规则

本页继承 `MASTER.md`。它服务于收盘后确认当日确定性结论、风险边界与复盘依据；盘后报告是按日期追加保存的历史事实，不用后续行情静默回写。

## 信息顺序

1. 页面说明：复盘日期、生成时点、数据状态与刷新入口。
2. 收盘结论：最重要的确定性结论、唯一主动作、风险等级、仓位边界和禁止条件。
3. 结构化依据：昨日持仓建议对账与推荐 T0/T1/T2/T5 回验；各证据独立展示完整、降级、缺失或失败状态。
4. 报告工作区：桌面端章节目录与安全渲染的正式复盘正文，保持单一阅读列。
5. 报告治理：版本、内容指纹、生成与推送状态，以及决策支持而非实盘指令说明。

## 交互与数据

- 读取 `/api/reports/close?date=YYYY-MM-DD`；`content_md`、`cockpit.command`、版本和生成时点均来自正式定稿，无正文时显示明确空态。
- 读取 `/api/holdings/advice-review`；`base_price/today_price` 单位为元，`change_pct/win_rate` 单位为百分数，真实空 `rows` 与接口失败分开。
- 读取 `/api/recommendations/stats` 与 `/api/recommendations`；胜率只接受 `win_rate_unit=percent`，推荐价单位为元，收益/MFE/MAE 为百分数，T0/T1/T2/T5 非评分状态分别展示。
- 回验使用 `/api/recommendations/verify`，只追加真实回验，不改写推荐；生成使用 `/api/reports/close/generate` SSE，推送使用 `/api/reports/close/push`。
- 任一接口失败仅降级对应区域，不清空已成功取得的报告或证据。
- `null` / `None`、`missing`、`degraded`、真实空数组和传输失败必须使用不同文案；不得用 `0` 或示例数字补位。
- 生成、刷新和推送动作必须防重复提交并提供明确状态；“已提交”不得表述为“已送达”。
- 报告、持仓建议、统计、推荐明细、生成、推送与回验分别使用独立 `AbortController`；页面卸载时取消在途请求、SSE reader，并清理定时器和 `visibilitychange` 监听。
- Markdown 解析为安全 Vue 节点，禁止直接渲染未经清洗的 `v-html`。

## 响应式

- 900px 以上：报告目录与正文并列；目录可 sticky，但页面只保留主滚动。
- 900px 以下：按阅读优先级改为单列，目录移到正文前方并可折叠。
- 宽表只允许在自身可聚焦容器内横向滚动；页面级不得出现横向滚动。
- 正文最大阅读宽度约 940px；移动端正文 18px，桌面端 16px。

## 验收

- 375 / 768 / 1024 / 1440px 无页面级横向滚动，所有可见交互目标至少 44×44px。
- 深浅主题分别满足 WCAG 2.1 AA；风险、涨跌及数据质量均同时使用文字或形状表达。
- 键盘可操作刷新、生成、推送、目录和正文跳转；章节跳转后标题可聚焦。
- 支持 `prefers-reduced-motion`；打印样式隐藏导航和动作控件，保留收盘结论、风险边界与正式正文。
