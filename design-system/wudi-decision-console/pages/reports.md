# 报告中心页面规则

> 本页规则覆盖 `MASTER.md` 的通用规则；未声明部分继续遵循主设计系统。

- Vue 路由：`#/history?tab=reports`
- 真实接口：`GET /api/archive/dates`、`GET /api/reports/{rtype}?date=YYYY-MM-DD`、
  `POST /api/reports/{rtype}/generate`、`POST /api/reports/{rtype}/push`、
  `GET /api/delivery/receipts?limit=100`。
- 技能检索曾返回“巨型 Hero + 夸张极简”模式；它与本项目高密度决策台及 `MASTER.md`
  冲突，本页不采用巨型 Hero、超大标题或额外动效，只采纳其 Vue 语义、响应式和无障碍规则。

## 用户任务与信息顺序

1. 先说明当前选中的报告类型、报告日期、生成时点与定稿状态。
2. 从服务端定稿报告中提取可见的结论摘要与唯一主动作；无法可靠提取时直接引导阅读正文，不在前端补写交易结论。
3. 明确展示服务端报告中的风险、仓位和禁止条件；字段或章节缺失时显示“未提供”，不得推断。
4. 展示报告版本、证据覆盖、数字校验和交付状态，使用户能判断依据是否完整、可靠、及时。
5. 正文采用安全 Vue 节点解析，并提供与正文同步的章节目录。
6. 历史日期和报告类型作为追加式事实切换；切换不会覆盖或改写既有报告。

## 页面结构

- 页首：标题、用途说明、报告日期、生成/定稿时点、数据状态和刷新动作。
- 决策摘要：当前结论、下一步、风险/仓位边界、禁止条件；只展示报告服务端事实。
- 报告选择：原生标签式链接或按钮，报告类型与日期均可键盘操作。
- 正文工作区：桌面为正文与章节目录双栏，窄屏改为单列；目录不得遮挡正文。
- 治理说明：版本、lineage、证据/数字校验、陈旧与降级原因、推送回执语义。

## 状态与缺失语义

- `loading`：保留正文工作区高度的骨架，不展示旧报告为新日期结果。
- 真实空：请求成功但该日期/类型没有报告，显示“该日期暂无已保存报告”。
- `missing`：字段未提供，显示“未提供”或 `—`，不得显示 0。
- `degraded` / stale：保留可用正文，并在摘要和治理区明确标注降级原因或数据日期。
- 接口失败：只让对应的报告读取、生成或推送区域降级；现有正文和其他控制保持可用。
- 不完整流：保留明确标记的临时生成内容，但不冒充已定稿报告，也不得触发推送。

## 动作语义

- 唯一主动作随状态变化：今日无报告时为“生成今日报告”，历史无报告时为“返回今天”；已有报告以阅读定稿为主，顶栏刷新只刷新状态而不改写历史。
- 生成、刷新、推送均使用原生 `<button>`，防重复提交并提供 `aria-live` 反馈。
- 可跳转章节使用真实 `<a href="#...">`；报告类型切换如不改变 URL，可使用原生按钮与选中状态。
- 推送反馈严格区分“请求已提交”“平台已接受”“已送达”“状态未知/失败”，不得以提交成功代替送达。

## 响应式与无障碍

- 1440px：摘要保持高密度，正文 `minmax(0, 1fr)`，目录宽度不超过 280px。
- 1024px：摘要允许两列，正文仍优先占据主要宽度。
- 768px 以下：摘要与正文单列，章节目录回到文档流且不 sticky。
- 375px：正文表格仅在自身可聚焦容器内横向滚动；页面本身不得横向滚动。
- 所有可见交互目标至少 44×44px；焦点环 3px；状态不用颜色单独表达。
- 移动端正文基准 18px，桌面端 16px；数字使用等宽字体与 `tabular-nums`。
- `prefers-reduced-motion: reduce` 下禁用骨架位移与非必要过渡。

## 禁止项

- 不从 Markdown 文本重新计算风险等级、仓位上限、价格区间或推荐结论。
- 不用未经清洗的 `v-html` 渲染报告。
- 不为报告中心请求行情榜单、全市场筛选等无关重型接口。
- 不在生产组件内放置审计示例数字或报告正文。
- 不修改原 `frontend/` 报告页或其他 Vue 业务页面。
