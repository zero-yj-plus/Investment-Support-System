# 尾盘决策页面规则

本页继承 `MASTER.md`。它服务于 14:52 正式尾盘结论确认，不把 14:45 草案或盘后波动冒充正式事实。

## 信息顺序

1. 页面说明：报告日期、正式定稿时点和“定格事实不回写”的口径。
2. 尾盘风险闸：能否参与、风险等级、仓位边界、第一原则和允许/禁止项。
3. 报告工作区：桌面端左侧章节目录、右侧唯一正式尾盘定稿；正文保持单一阅读列。
4. 执行前证据：推荐留痕与 T0/T1/T2/T5 回验、观察池 A—E 就绪机会。
5. 报告治理：版本、内容指纹、推送状态与“候选提案非下单指令”说明。

## 交互与数据

- 读取 `/api/reports/tail?date=YYYY-MM-DD`；无定稿时显示明确空态，不生成示例内容。
- 并行读取 `/api/recommendations/stats`、`/api/recommendations` 和 `/api/watchlist`；任一失败不得拖垮其他卡片或报告。
- 推荐统计只在 `win_rate_unit=percent` 时格式化胜率；未知单位保持缺失，不猜测换算。
- 观察池只展示服务端 `grade/status/target_low/target_high/quote`；目标区间任一端缺失时显示 `—`。
- 回验使用 `/api/recommendations/verify`，结果只追加，不改写既有推荐事实。
- 生成使用 `/api/reports/tail/generate` SSE；不完整流不得冒充正式定稿。
- 推送使用 `/api/reports/tail/push`；“已提交推送”不表述为对方已读或最终送达。
- 证据每 30 秒局部刷新，页面恢复可见时补刷新；卸载时取消报告、统计、推荐、观察池和动作请求并清理定时器。
- Markdown 必须解析为安全的 Vue 节点，禁止直接使用未清洗的 `v-html`。

## 响应式

- 1100px 以上：推荐回验与观察池双栏；以下改为单栏。
- 900px 以上：报告目录 268px，正文 `minmax(0, 1fr)`；目录可 sticky，页面只保留主滚动。
- 720px 以下：风险闸、证据表和报告工作区转为单列，观察池行改为堆叠信息，不产生页面级横向滚动。
- 正文最大阅读宽度约 940px；移动端正文 18px，桌面端 16px。

## 验收

- 375 / 768 / 1024 / 1440px 无页面级横向滚动，所有交互目标至少 44×44px。
- 深浅主题分别通过 WCAG 2.1 AA；风险等级同时显示文字和固定色。
- 键盘可操作导航、回验、目录、打印、推送、生成和刷新；章节跳转后标题可聚焦。
- 支持 `prefers-reduced-motion`；打印样式隐藏导航、证据卡和交互控件，保留定格风险闸与正式正文。
