# 问股页规则

> 路由：`#/research?tab=ask`。本页只承载盘中个股问答，不提供自由问答、持仓诊断或产业链挖掘入口。

## 用户任务与信息顺序

1. 标题区说明当前为“专属盘中问股”，并展示服务端交易阶段与当前标的数据时点。
2. 用户在“盘中问股”表头输入六位 A 股代码；页面只在显式查询后读取该标的首屏行情与增强证据。
3. 对话区优先呈现服务端治理后的“直接回答、现在怎么做、失效条件与依据”；AI 只能补充解释。
4. 标的证据区展示价格、涨跌幅、盘口边界、行业概念、资金流日期和缺失项，不在浏览器重算交易动作。
5. “盘中问股”表头下方提供渐进展开的“分析视角”选择；默认不启用，用户每轮可从服务端 17 个白名单视角中选择最多 4 个。
6. 底部依次为两行推荐问题、待发送图片和等高输入/上传/发送控件。
7. 历史会话只显示 `mode=stock`；旧会话没有可复核代码时要求重新选择标的，不从自然语言猜代码；已完成回答显示当轮使用的视角名称。

## 数据状态

- `core.state=complete`：行情与最近日 K 均可用；`partial`：只展示已返回模块并列出缺失项。
- `recognized=false` / `state=not_found`：明确提示代码不在完整 A 股名录，不生成问股动作。
- `recognized=true` 且 `quote=null`：股票已识别但报价暂不可用，不得称为代码不存在。
- `enrichment` 失败只让行业、资金或财务证据局部降级；不得清空已成功的首屏行情或对话。
- `flow_date` 早于当前交易日时标记“上一交易日”；集合竞价 `unavailable` 不显示模拟值。
- SSE 未返回 `done` 的内容标记“未完整输出”，不加入历史、导出或下一轮上下文。
- 对话列表成功返回空数组是“暂无问股记录”；传输失败是“历史暂不可用”，两者不可混同。

## 布局与交互

- 卡片使用 1px 边框、8px 圆角、无装饰性阴影；正文遵循桌面 16px、移动端 18px 基准。
- 桌面为历史栏、对话主区、标的证据栏三段布局；历史栏默认折叠为 56px 的可访问开关，用户显式展开后才显示记录并占用 190–220px。低于 1180px 将证据栏移到对话下方，低于 800px 全部单列。
- 桌面端对话区使用视口内固定工作台，表头、分析视角和输入区不随消息滚动，仅消息列表内部纵向滚动；800px 以下恢复文档流，避免窄屏嵌套滚动和内容遮挡。
- 推荐问题使用 CSS Grid：桌面端为两行 40px 紧凑按钮，列宽从 138px 起自适应；800px 以下恢复 44px 触控高度和 140px 列宽，可以在自身区域横向滚动，但不得造成页面级横向滚动。
- 输入框、上传按钮和发送/停止按钮共用同一高度令牌，均不低于 52px；输入框内部滚动，不用自动增高破坏等高关系。
- 股票代码查询控件位于“盘中问股”表头，必须有可见 `<label>`、`inputmode="numeric"`，校验错误紧邻输入并通过 `role="alert"` 通知。
- 历史开关使用原生 `<button>`、`aria-expanded` 与 `aria-controls`；默认收起，收起后不得保留不可见但可聚焦的历史操作。
- 分析视角开关同样使用原生 `<button>`、`aria-expanded` 与 `aria-controls`；选项使用原生复选框且仅显示名称，按“短线与游资 / 宏观与趋势”分组。达到 4 个上限后禁用其余未选项，但必须允许取消已选项，并以文字显示“已选 X/4”和恢复方式。
- 17 个视角采用最小 140px 的紧凑自适应网格，720px 以下单列；展开区高度受视口约束并允许自身滚动。选择状态变化不得依赖颜色单独表达。
- 所有执行动作用原生 `<button>`，页面跳转用 `<a>`；可见交互目标至少 44×44px，`:focus-visible` 使用 3px 焦点环。
- Enter 发送、Shift+Enter 换行；生成中发送按钮变为“停止”，重复提交被禁用。

## 安全、生命周期与响应式

- Markdown 只使用 `parseReportMarkdown` 生成 Vue 文本节点，禁止 `v-html`。
- 首屏、增强、会话、消息保存与 SSE 分别使用职责明确的 `AbortController`；新查询取消旧标的请求。
- 卸载时取消全部请求和 SSE reader、清理阶段计时器、文件读取状态与 `visibilitychange` 监听，并用 generation/alive guard 阻止陈旧响应写状态。
- 375px 采用单列、18px 正文和 52px 编辑控件；1440px 对话主区优先，证据栏不超过 320px。
- 页面根、Grid 子项和消息内容均设 `min-width:0`；只有推荐问题带允许键盘聚焦的局部横向滚动。
- 深浅主题均使用 MASTER 语义令牌，风险状态始终配文字，行情涨跌色不表达风险等级。
- 遵守 `prefers-reduced-motion`；加载动画只用于请求反馈。

## 审计场景

- 375px 深色：加载中、初始空态、代码错误、同高编辑控件和两行推荐问题。
- 1440px 深色/浅色：完整行情、局部增强失败、长 Markdown 回答、历史栏与证据栏。
- 所有场景检查页面级横向溢出、44px 交互目标、原生语义和 axe WCAG 2.1 AA。
