# 次日策略页面规则

本页继承 `MASTER.md`。它服务于 19:30 形成下一交易日作战计划；今日尾盘与收盘定稿是不可回写的上游事实，晚间新增信息只能构造明日条件。

## 信息顺序

1. 页面说明：策略数据日期、19:30 实际生成时点和上游事实冻结口径。
2. 风险底座：服务端风险等级、唯一主动作、仓位边界、第一原则和禁止条件；明确该快照仍需明日开盘重新验证。
3. 结构化证据：观察池 A—E 排序，以及尾盘/收盘同日定稿 lineage、治理和推送状态。
4. 报告工作区：章节目录与安全渲染的唯一正式次日计划，保持单一阅读列。
5. 治理说明：候选提案不计胜率、不构成下单；价格区间、筛选和风险结论仍以服务端为准。

## 交互与数据

- 读取 `/api/reports/evening?date=YYYY-MM-DD`；正文、风险快照、生成时点、版本、指纹和 `input_lineage` 均来自正式定稿。
- 读取 `/api/watchlist`；`quote.price`、`target_low/target_high` 单位为元，`quote.change_pct` 单位为百分数，`grade/status` 直接展示服务端确定性结果。
- 观察池任一区间端点缺失时整体显示 `—`；`null`、`missing`、陈旧报价、真实空数组和接口失败使用不同文案。
- 报告与观察池独立请求、独立降级；页面常驻时只每 30 秒局部刷新观察池，恢复可见时补刷新两者。
- 生成使用 `/api/reports/evening/generate` SSE；不完整流不得冒充定稿。推送使用 `/api/reports/evening/push`；成功只写“已提交推送，未确认送达”。
- 报告、观察池、生成和推送分别使用 `AbortController`；卸载时取消请求、SSE reader，清理定时器与 `visibilitychange` 监听。
- Markdown 解析为安全 Vue 节点，不使用未经清洗的 `v-html`。

## 响应式

- 1100px 以上：观察池与数据健康按 `1.25fr / .75fr` 双栏；以下按阅读顺序改为单列。
- 900px 以上：报告目录 268px，正文 `minmax(0, 1fr)`；目录可 sticky，页面只保留主滚动。
- 720px 以下：风险底座、证据和报告工作区均为单列；观察池行转为两列信息卡。
- 520px 以下：观察池行改为完整单列；不得出现页面级横向滚动。
- 宽表只允许在报告自身可聚焦容器内横向滚动；正文移动端 18px、桌面端 16px。

## 验收

- 375 / 768 / 1024 / 1440px 无页面级横向滚动；所有可见按钮和链接至少 44×44px。
- 深浅主题分别满足 WCAG 2.1 AA；风险、涨跌与数据质量均有文字语义，不单靠颜色。
- 键盘可操作刷新、生成、推送、观察池链接、目录和章节跳转；焦点状态清晰。
- 支持 `prefers-reduced-motion`；打印样式隐藏导航、证据卡和动作，保留风险底座与正式正文。
